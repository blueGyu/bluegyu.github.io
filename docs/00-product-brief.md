# 00. Product Brief (요구사항 요약)

## 배경
- 현재 히스토리(글) 0개 상태에서 시작.
- 먼저 “비어있어도 배포 가능한 포트폴리오”를 만들고, 이후 프로젝트/글을 추가하며 히스토리를 쌓는다.

## 목표
- 채용 담당자가 1~2분 안에 파악할 수 있는 구조
- 백엔드/바이브 코딩 지향성을 드러내는 콘텐츠 구성
- 빠르고 단순한 구현: 기본 웹 + 다크모드 + 카드/버튼 + 가벼운 애니메이션

## 타겟 사용자
- 채용 담당자(리크루터), 팀 리드/시니어 엔지니어
- 함께 일했던 협업자(레퍼런스 확인)

## 핵심 메시지(포지셔닝)
- “Node.js/Express + PostgreSQL 기반 구현 경험이 있고, 협업을 통해 제품을 만들 수 있는 주니어”
- “자동화/콘텐츠 생성 파이프라인(새 프로젝트)로 문제 해결 능력을 보여줄 예정”

## 필수 기능
- 홈(/): 소개 + 프로젝트 카드 + 글(작성 목록) + 연락처
- 프로젝트(/projects, /projects/[slug]): 카드 목록 + 상세
- 글(/writing, /writing/[slug]): 목록 + 상세
- 다크모드: 토글 + 시스템 모드 지원
- 기본 SEO: title/description, OG 메타 최소

## 제외 기능
- 로그인/댓글/검색/태그 페이지/관리자 CMS(초기)
- 외부 API 호출/DB(정적 콘텐츠로 운영)

## 성공 기준(정성/정량)
- “내가 무엇을 했는지/무엇을 잘하는지/어떤 프로젝트를 했는지”가 홈에서 즉시 보인다.
- 프로젝트/글을 추가하는 데 개발 작업 없이 Markdown 파일만 추가하면 된다.
- Lighthouse/성능/접근성에서 기본 수준 이상(보수적 목표: 90+)
