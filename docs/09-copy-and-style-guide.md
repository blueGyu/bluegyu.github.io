# 09. Copy & Style Guide (채용용 글쓰기 가이드)

## 톤
- 짧고 명확하게, “내가 한 일”을 주어로 쓴다.
- 모호한 표현 대신 **구체적 행동/결과/근거**를 넣는다.

## 권장 구조
- 문제(Why) → 접근(How) → 결과(What) → 배운 점(Learnings)

## 좋은 문장 예시
- “Express로 인증/인가 미들웨어를 분리해 라우트별 정책 적용을 단순화했다.”
- “PostgreSQL 인덱스를 추가하고 쿼리 플랜을 확인해 응답 시간을 개선했다.”

## 피해야 할 문장
- “열심히 했다 / 많이 배웠다 / 최선을 다했다” (근거 없이 추상적)
- “좋은 아키텍처로 만들었다” (무엇이/왜 좋은지 없음)

## 프로젝트 카드 텍스트 팁
- 1문장 요약에는 “기술 + 목적 + 가치”를 넣는다.
- 예) “단어 입력 → 위로 영상 자동 생성 → 플랫폼 업로드/피드백 자동화 파이프라인 구축”
