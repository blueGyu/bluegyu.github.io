# 07. Definition of Done (초기 버전 완료 기준)

## 기능
- [ ] 다크모드 토글이 동작한다(라이트/다크/시스템).
- [ ] `/projects` 목록과 `/projects/[slug]` 상세가 동작한다.
- [ ] `/writing` 목록과 `/writing/[slug]` 상세가 동작한다.
- [ ] posts가 0개여도 Empty state가 자연스럽다.
- [ ] Markdown 추가만으로 콘텐츠가 반영된다(draft 제외 규칙 포함).

## UI/UX
- [ ] 모바일/데스크탑 반응형이 깨지지 않는다.
- [ ] 버튼/카드 hover가 과하지 않고 일관된다.
- [ ] 네비게이션으로 주요 섹션/페이지 접근 가능.

## 품질
- [ ] `npm run lint` 통과
- [ ] `npm run build` 통과
- [ ] 접근성: focus-visible, aria-label, 링크/버튼 구분
- [ ] 기본 SEO title/description 적용

## 운영
- [ ] `docs/`가 “어떻게 글을 추가하는지”를 충분히 설명한다.
- [ ] 배포 방법이 문서화되어 있다.
